## Cursor

`lib/playback/score-following/` holds the shared, UI-free model. `cursor-model.ts` resolves the latest ChordRest
segment whose played start is at or before the presentation time. It uses the engine's `segmentPositions` events,
which are repeat-expanded and tempo-aware under the current options revision. Measure positions are the fallback
when segment positions are unusable, and with neither, tracking is reported unavailable. There is no cursor before
the first event; the final event holds through the release tail. Placeholders from progressive layout keep their
timing and report `geometry: false`, so no coordinates are guessed for an unlaid page. The cursor never sweeps
through a measure.

`components/score-editor/score-following/` is the editor feature folder:

- `usePlaybackFollowing` reads the map once the stream is live, never on the Play critical path. It re-reads it for
  each new session, for a new options revision, and on page changes while layout is incomplete. It returns a stable
  controller of refs, so the editor root re-renders only on transport state changes, not per segment.
- `PlaybackFollowLayer` draws a pointer-transparent bar across the active system (a dashed outline in measure
  fallback) inside the zoomed wrapper. It has a white outline, so it stays visible over selection colours without
  relying on colour alone. It subscribes to the transport's position ticks and re-renders only when the discrete
  segment changes. It never touches selection, `selectedPoint`, the note-input cursor or focus.

Count-in holds the cursor at the music start; pause freezes it (no ticks); Stop/idle removes it. A hidden tab stops
animation frames and reconciles from the audio clock when it returns.

## Following

Follow playback is a remembered preference, on by default (`ots-editor-follow`). When the cursor's page is not the
visible one, the layer calls the existing `goToPage`; a navigation dropped because another is in flight is retried.
Within a page it works per system: viewport work happens only when the system changes, and only if the system leaves
the safe band (10–80% of the height). Revealed systems land near the top, so the next one stays in view, and the
cursor is revealed horizontally at high zoom. Under `prefers-reduced-motion` scrolling jumps rather than animates.

Manual input suspends following for the rest of the session, with no timer: wheel, touch drag, scroll keys, the
scrollbar, or any page change the layer did not request. Commands registered in the shell (Playback menu and
palette):

- `playback.follow`: toggle, announced.
- `playback.jumpToPlayback`: reveal once, leaving following suspended.
- `playback.resumeFollowing`: clear the suspension and reveal.

The header transport shows the Follow toggle. While suspended it adds Resume following and a "Playing on page N"
jump button, and during playback a "Click a note to seek" or "Tracking unavailable" hint. Host surfaces (scanner,
change review, compare embed) have no header and play through compare transports, not the editor transport, so
there is no separate host chrome to extend.

## Contextual click-to-seek

`score-click.ts` asks the controller first, before any selection, note-input or grip work. A seek happens only for
an unmodified click on a note, rest or their parts, while the transport is playing (not paused, stopped or in note
input), on a laid-out element of the visible page. The seek prefers the element's pass inside the repeat run now
playing, then its next pass, then its first. It shows a short seek marker and returns without selecting, auditioning
or mutating. Modified clicks, marquee, drags (including note repitch, which stays an edit and stops playback), text
editing and note entry keep their meaning. Stopped or paused clicks select as before.

Transport fix found here: `seek` and options changes share `allowAnyStart`. A selection iterator cannot start
elsewhere, so seeking during play-from-selection restarts as a full stream at the target (previously it restarted
at the selection). Continuing at a new place no longer replays the count-in.
